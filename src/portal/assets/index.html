ℹ This page stands in for a Remote screen with no public API. What that means, and what it does not

This stands in for Remote product surfaces that have no public API. An expense, a trip, a resignation, a relocation — in the real product these requests begin inside Remote, and Remote emits no public event for any of them. This page is that missing surface, and it is not Remote's product, design or endpoint.

The gates it runs are the real ones. Every submission calls the use case's actual handle*() function in this process; nothing is re-implemented here.

The employee records are mock fixtures, not your Remote Sandbox. Remote reads here are served by this repo's mock Remote server, called in-process, because a page anyone can reach must not read or write a real account. Decisions are still real, and still audited.

Every employee persona carries a real Sandbox employment id.     Consent requests

    Third parties who have asked to have your own employment confirmed, and have not yet been answered. Only you can grant or refuse a request about yourself — nobody else can decide this for you, and it never happens anywhere else on this page.

    Deciding here answers exactly ONE request, from ONE party, for ONE stated purpose — never a standing "yes to anyone, forever". A different party asking, or the same party asking for something else, is a different request and asks again. Granting still does not disclose anything by itself: it records that you said yes, and the request that asked is what acts on it next.
